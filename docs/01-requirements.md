# متطلبات منصة إدارة المنح (S002)

**المصدر الأساسي:** وثيقة متطلبات الأعمال — برنامج إدارة المنح (S002)، ClickUp، آخر تحديث ٢١ سبتمبر ٢٠٢٦.
**الإضافات:** أفضل الممارسات العالمية في المنح ومنصاتها، ومبدأ AI-first، والتصور التقني و HLD المعتمدان.
**العميل المرجعي:** مؤسسة نورة الملاحي. **الموعد:** الدورة كاملة تعمل عندها نهاية نوفمبر ٢٠٢٦.

هذا الملف هو مرجع البناء. كل متطلب له رقم ثابت يحمله اختباره في الكود. أي تعارض بين هذا الملف ووثيقة الأعمال الأصلية: الأصلية تحكم، ويُسجَّل التعارض في `docs/decisions.md`.

---

## ١. المنتج في سطرين

منتج سحابي يدير دورة المنحة كاملة عند الجهة المانحة، من تهيئة السياسات حتى إقفال المشروع، ويُباع لأكثر من مانح بالإعدادات لا بالتخصيص البرمجي.
يأتي مهيأً لا فارغاً، والذكاء الاصطناعي فيه طبقة عمل لا ميزة جانبية: النظام والوكيل ينفذان الإجراءات، والأخصائي يحكم ويوصي.

## ٢. أهداف النجاح

| الهدف | المؤشر |
| --- | --- |
| دورة كاملة عند الملاحي | طلب حقيقي من التقديم إلى الصرف داخل النظام قبل نهاية نوفمبر ٢٠٢٦ |
| وقت الأخصائي للحكم | الأخصائي يفتح ملف دراسة جاهزاً؛ قياس: متوسط زمن الدراسة لكل طلب، وعدد الإجراءات اليدوية لكل طلب |
| مرجعية الحوكمة | أي قرار يُستوضح كاملاً من صفحة حيثيات واحدة |
| قابلية البيع | عميل ثانٍ يُهيَّأ بالإعدادات دون تخصيص برمجي |
| عبء أقل على الجمعيات | زمن تعبئة الطلب، ونسبة الطلبات المكتملة من أول إرسال |
| انتشار | ١٠ مانحين مشتركين بنهاية ٢٠٢٧ (ملتزم)، و١٥ طموحاً |

## ٣. المبادئ الحاكمة

### ٣.١ مبادئ وثيقة الأعمال (لا تُكسر)

1. **كامل عرضاً، مقتصد عمقاً.** كل مراحل الدورة تعمل، وكل مرحلة بأبسط صيغة تؤدي الغرض.
2. **مهيأ افتراضياً بأفضل شكل.** يعمل دون فتح الإعدادات.
3. **تحكم كامل بالإعدادات دون محرك سير عمل حر.** هيكل ثابت للدورة، وسلاسل خطية بشروط.
4. **سجل لكل شيء.** تدقيق غير قابل للتعديل، وسجل نشاط مقروء في كل صفحة.
5. **بسيط وعملي.** «مهامي» نقطة الدخول، وموظف جديد يدرس طلباً دون تدريب.
6. **الوصول للمعلومة في خطوتين:** بحث ثم صفحة. كل ذكر لعنصر رابط لصفحته.
7. **الأخصائي يحكم ويوصي.** كل ما عدا ذلك ينفذه النظام أو الوكيل.

### ٣.٢ مبادئ AI-first (إضافة)

| المبدأ | ماذا يعني في المنتج |
| --- | --- |
| الذكاء يجهّز، الإنسان يقرر | كل مخرج للذكاء مسودة أو اقتراح بحالة «بانتظار الاعتماد». لا يغيّر حالة أي كيان بنفسه |
| الذكاء في مكان العمل | لا «صفحة ذكاء» منفصلة. الاقتراح يظهر في الحقل أو الملف أو الشاشة التي يعمل فيها المستخدم |
| كل حكم بدليله | كل درجة أو علامة أو ملخص يشير إلى موضعه في المرفق (الملف، الصفحة، المقطع) |
| شفافية المصدر | كل نص ولّده الذكاء موسوم بذلك، ومعه زر «ما مصدر هذا؟» |
| الحتمي حتمي | الأهلية والسقوف والتكرار والموانع جداول قرار في النظام، لا مهام للنموذج |
| يعمل والذكاء معطّل | لكل مهمة ذكية بديل يدوي، ودورة كاملة تمر في الاختبارات والذكاء معطّل |
| التقييم قبل الضبط | مجموعة تقييم من طلبات حقيقية قبل أي ضبط للـ prompts، وعتبات توقف الإصدار |
| تغذية راجعة | كل مخرج ذكي يقبل «مفيد / غير مفيد + سبب»، ويغذي مجموعة التقييم |

## ٥. الدورة

عشر مراحل ومساران فرعيان. التنفيذ والصرف يتكرران لكل دفعة، وطلب التعديل يُفتح في أي وقت أثناء التنفيذ.

```
التهيئة → تسجيل الجمعية → الجاهزية والتقديم → التوزيع → الدراسة → الاعتماد
        → الاتفاقية → التنفيذ والتسليمات ⇄ الصرف → الإقفال
مساران فرعيان: طلب التعديل، والمورّد
```

قواعد كل مرحلة مفصلة في وثيقة الأعمال (القسم ٦) ومُلخصة في كتالوج المتطلبات أدناه. لا تُضاف حالة ولا يتغير اتجاه انتقال إلا بقرار مسجل.

## ٧. خارج النطاق

**مؤجل (بعد التسعين يوماً، دون إعادة هيكلة):** منشئ نماذج بالسحب والإفلات، نفاذ، الحساب الموحد عبر المانحين، الربط مع الموارد البشرية والنظام المالي، الترحيل الآلي، تقييم بلجان متعددة المقيّمين، تصويت اللجنة داخل النظام، التوقيع الإلكتروني المدمج، إطار قياس الأثر، التصنيف المحسوب آلياً، لوحات يبنيها المستخدم، البحث داخل المرفقات والدلالي، اقتراح منفذين، تطبيق جوال، التعديل بالمحادثة.

## ٩. معايير قبول الإطلاق

الإطلاق عند الملاحي لا يتم إلا إذا تحققت كلها:

- [ ] كل متطلبات «لازم» (R و N) لها اختبار يحمل رقمها ويمر.
- [ ] طلب من عينة الملاحي يعبر الدورة كاملة على بيئة التجهيز مرتين: بالذكاء ومعطّلاً.
- [ ] اختبار العزل العدائي ومصفوفة الصلاحيات يمران.
- [ ] مجموعة تقييم مانح تتجاوز العتبات المثبتة.
- [ ] اختبار استرجاع من النسخ الاحتياطي ناجح.
- [ ] فحص الوصولية (axe) بلا أخطاء حرجة على الشاشات الأساسية.
- [ ] ملف الثقة جاهز ومراجَع.
- [ ] نتائج اختبار الاختراق الحرجة والعالية معالجة.
