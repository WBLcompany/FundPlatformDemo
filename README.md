## البدء

1. أنشئ مستودعاً جديداً وانسخ محتوى الحزمة إلى جذره.
2. أضف ملفات الهوية: الشعار SVG في `public/brand/`، وخطوط Ko Sans (بعد الرخصة) في `apps/web/public/fonts/`.
3. أضف Figma MCP: `claude mcp add --transport http figma https://mcp.figma.com/mcp` ثم وثّقه من `/mcp`.
4. افتح Claude Code في المستودع وابدأ بـ `/task T-01`.

## ما ينتظر قراراً قبل س١

- **Q-1** طريقة الاستضافة داخل المملكة (تجربة T-08 تجهّز المقارنة).
- **Q-2** مزود النموذج اللغوي ومكان المعالجة.
- **Q-7** رخصة Ko Sans للويب.
- ملفات الشعار ومكتبة الأيقونات البكسلية من فريق الهوية.
- تصحيح دليل الهوية: صفحة الخط البديل تذكر «WBL Favorit Arabic» بدل Ko Sans.
